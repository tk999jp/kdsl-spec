# KDSL Core — 最小演算子／文型

## 記号

| 記号 | 意味 | 例 |
|---|---|---|
| `:` | 見出／定義 | `目的: 表示補正` |
| `/` | 並列列挙 | `調査/実装/試験` |
| `,` | 軽分節 | `編集可,commit承認待` |
| `;` | 規則分節 | `対象:A;非対象:B` |
| `→` | 条件／遷移 | `失敗→src保持` |
| `=>` | 変換 | `自然文=>KDSL` |
| `>` | 優先 | `U確定>提案` |
| `=` | 略語定義／短同値 | `基点=旧Core` |
| `:=` | 扱／状態指定 | `実機:=未確認` |
| `×` | 衝突／不可 | `条件衝突×` |

行頭`>`禁止（Markdown引用と衝突）。`=`を状態指定へ使わず`:=`を使用。`/`は選択／orを意味しない。`×`だけで明示禁止を代替しない。

## 文型

```text
X禁止
X未確認→確認済扱禁止
X未実行→実行済扱禁止
X時→Y
X不可→停止
X衝突→Y優先
A:=状態
A>B
```

`→`は条件と手順の両方を表せるため、両者が混在して読み違える箇所だけ役割ラベルを補う。

```text
条件: src空→削除／src非空→保持
手順: 現状確認→補正→試験
```

複数条件で`/`をORとして推測させない。必要時は`条件: AかつB→C`、`条件: AまたはB→C`と短い日本語制御語を用いる。括弧を省略すると作用範囲が変わる場合は省略しない。

## 圧縮規則

```text
同義反復→統合
同一長値／固定条件→1回定義＋参照
KEYのみ漢字化→圧縮未成立
不可侵制約の削除／反転／弱化禁止
技術識別子(command／path／API名等)→文字列完全保持
```

短名は説明用の参照でありshell変数ではない。inline commandに短名を未展開literalとして挿入禁止。必要なcommandは実値を保持する。
