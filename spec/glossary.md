# KDSL 用語（再構築候補）

```text
KDSL:=日本語漢字圧縮DSL
KDSL-Intl:=非漢字派生subset
Core:=言語identity／演算子／mode
profile:=用途別変換規則
min:=通常圧縮
dense:=高圧縮
限定保護:=U明示重大条件の意味消失防止
KDSL_PROMPT:=AI coding向け圧縮指示先頭block
KDSL-DP:=ADPS向けAuthoring形式（直接実行不可）
R1／KDSL_RESULT:=作業結果の簡潔報告
RT:v:=対象環境runtime確認済
```

`Agent`、`P1/P1L`、`K1/PF1`は必要な外部層で使用し、KDSLのidentityへ取り込まない。
